# V2.2 lightweight cross-view instance graph

## What changed

V2.1 associated view-local SAM masks through shared individual Gaussian centres.
V2.2 keeps the trained 3DGS and SAGA models unchanged, but inserts a higher-level
instance graph after SAM projection:

1. Spatial voxel grouping reduces 61,380 Gaussians to a target of 1,600 compact
   anchors/superpoints. Dense voxels are split along their longest axis with a hard
   128-Gaussian cap, producing 1,911 anchors in the checked scene. Each anchor stores
   its centroid and mean normalized SAGA feature.
2. A projected-centre z-buffer rejects occluded points. Each visible point selects
   the smallest containing SAM mask, and the mask votes for anchors by visible-member
   support instead of voting independently for every Gaussian.
3. Cross-view mask-node affinity combines five signals: weighted 3D anchor overlap,
   shared visibility/containment, RGB object-and-ring context, SAGA cosine similarity,
   and spatial anchor connectivity.
4. Multi-view unary votes and graph pairwise weights are optimized by deterministic
   ICM. Disconnected islands with the same provisional label are cut into separate
   instances.
5. Only anchors touching another positive instance label are considered boundaries.
   Their members are refined with accumulated anchor votes and Gaussian SAGA similarity;
   interior anchors are assigned once as a unit.

The implementation is in `segmentation/instance_graph.py`; the
`segmentation.sam_driven` module exposes the same GUI entry point and adds
`--target_anchors`, `--max_anchor_points`,
`--graph_threshold`, and `--diagnostics` for standalone use.

## Reproduce the real-data comparison

The checked run uses the local Mip-NeRF360 `bicycle` scene, 61,380 trained Gaussians,
32-D SAGA features, and all 194 views (`sample_rate=1.0`). V2.1 required a
runtime compatibility alias because its code calls a PyTorch API absent from the
installed environment; the baseline algorithm itself was not changed.

```bash
conda run -n gaussian_splatting_v2 python -m segmentation.sam_driven \
  -m output-v2/smoke_scene -s 610 -f 4 --sample_rate 1.0 \
  --target_anchors 1600 --max_anchor_points 128 --graph_threshold 0.50 \
  --diagnostics comparisons/bicycle/v2.2_diagnostics.json \
  -o comparisons/bicycle/v2.2_mask.pt

conda run -n gaussian_splatting_v2 python -m tools.benchmarks.compare_instance_versions \
  -m output-v2/smoke_scene \
  --v21_mask comparisons/bicycle/v2.1_mask.pt \
  --v22_mask comparisons/bicycle/v2.2_mask.pt \
  --sample_rate 1.0 --output_dir comparisons/bicycle
```

| Metric | V2.1 | V2.2 | Interpretation |
|---|---:|---:|---|
| Instances | 4 | 10 | V2.2 currently over-splits the scene |
| Gaussian coverage | 68.41% | 77.19% | anchors recover jointly supported members |
| SAM mask agreement | 98.59% | 95.44% | regression; boundary/association calibration is needed |
| Anchor purity | 95.02% | 98.99% | fewer mixed-label anchors |
| Spatial components / instance | 4.50 | 1.10 | substantially less internal fragmentation |
| Cross-instance anchor edges | 4.03% | 2.96% | lower boundary interleaving |
| SAGA coherence | 0.1154 | 0.1295 | stronger within-instance feature consistency |

V2.2 created 1,911 bounded-size anchors and 9,438 sparse edges, processed 2,759 mask
nodes, and refined 3,691 boundary Gaussians (6.0% of the scene). Raw values are in `comparisons/bicycle/metrics.json`
and `comparisons/bicycle/v2.2_diagnostics.json`; the visual comparison is
`comparisons/bicycle/real_bicycle_comparison.png`.

These are consistency proxies, not instance mIoU: this local bicycle copy has no 3D
instance ground truth. The visual overlays reveal that both versions inherit SAM/SAGA
leakage into nearby vegetation and ground. V2.2 improves spatial connectivity, anchor
purity, feature coherence, and coverage, but its lower SAM agreement and 10-vs-4
instance count expose over-segmentation. It does not yet establish benchmark superiority.

## Paper basis

- [SAGA](https://arxiv.org/abs/2312.00860) supplies the retained scale-aware Gaussian
  affinity features.
- [AG²aussian (ICCV 2025)](https://openaccess.thecvf.com/content/ICCV2025/html/Wang_AG2aussian_Anchor-Graph_Structured_Gaussian_Splatting_for_Instance-Level_3D_Scene_Understanding_ICCV_2025_paper.html)
  motivates organizing small Gaussian groups around semantic anchors and using graph
  propagation for cleaner instance selection. V2.2 borrows the organization principle,
  not its trainable representation.
- [OpenInsGaussian](https://arxiv.org/abs/2510.18253) motivates context-aware mask
  descriptors and selective cross-view fusion. V2.2 uses a lightweight deterministic
  RGB object/ring descriptor instead of its learned attention module.
- [SAI3D](https://cvpr.thecvf.com/virtual/2024/poster/29714) supports combining SAM
  semantic cues with geometric priors for zero-shot 3D instance organization.

## Continued update plan

### V2.3: evaluation and adaptive anchors

- Add ground-truth evaluation on scenes with 3D instance labels: instance mIoU,
  boundary IoU, association F1, over/under-segmentation, and per-view stability.
- Replace a single global voxel scale with density- and Gaussian-scale-aware anchors;
  split anchors when SAGA variance or projected boundary entropy is high.
- Tune graph weights on a held-out scene and report a sensitivity sweep rather than a
  single threshold. Success gate: improve boundary IoU and fragmentation without more
  than 10% runtime or memory regression.

### V2.4: learned cross-view fusion

- Replace handcrafted context with a compact frozen image embedding and learn a
  calibrated edge scorer from geometry, visibility, context, SAGA, and connectivity.
- Add camera-overlap neighbourhoods rather than relying only on sorted-view windows.
- Introduce confidence-aware background/unobserved states and explicit graph-cut energy.
  Success gate: higher association F1 on occluded and repeated-appearance objects.

### V2.5: training-time anchor regularization

- Jointly regularize anchor compactness, within-anchor SAGA variance, and boundary
  separation while retaining the existing 3DGS renderer.
- Add hierarchical anchors for part/object/scene granularity and stable persistent
  instance IDs for editing/export.
- Benchmark against SAGA, Gaussian Grouping/OpenGaussian, AG²aussian, and
  OpenInsGaussian under identical cameras, masks, and evaluation labels.
